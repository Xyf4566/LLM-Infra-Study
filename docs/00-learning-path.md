# LLM Infra 学习路径

更新日期：2026-10-21。阶段安排可随讨论调整，每个阶段可以拆成多篇学习篇章。

## 起点与实践条件

- 数学背景：普通数学本科，已有线性代数、概率和微积分基础。
- 编程背景：已有基础 Python、NumPy、PyTorch 使用与实践经验。这部分安排为随章节巩固、诊断和练习。
- 本地机器：AMD Ryzen 7 9700X、RTX 5070 Ti、48GB DDR5 系统内存。
- GPU 实验按标准 RTX 5070 Ti 的 16GB 显存设计，实施时核对实际可用显存、驱动与 PyTorch 支持。系统内存与显存分别核算。

## 资料的使用方式

1. D2L 用于基础概念、推导和小实验，重点阅读语言模型与注意力相关章节。
2. CS336 2025 讲义用于串联模型、数据、训练、评估、推理和系统。其作业另行选取并缩小到单机规模。
3. GPU MODE 按主题穿插，先做 profiling，再逐步进入 CUDA、Triton、通信与工程案例。
4. 前沿部分持续补充官方论文、仓库和技术报告。DSpark、DeepInfer 等属于案例，课程终点是具备跨层分析与验证能力。

参考仓库的位置、来源、版本与获取方式见 [资料索引](../refs/README.md)。

阶段 7–12 根据前置知识交叉推进。CPU 和单 GPU 的实验可以验证算法与局部行为；集群扩展、RDMA 和跨机故障恢复需要另外的硬件或公开测量资料。

后续预训练以小型自建模型为主；现有模型推理先选 0.5B–3B 量级，再根据实测显存扩展。消费级 GPU 上的 kernel 选择需核对其架构支持，不能直接套用面向数据中心 GPU 的配置。

## 每篇的组织

围绕一个具体问题，依次进行：历史动机 → 概念与数学推导 → 小例子 → 实验与可视化 → 结果解释 → 与后续系统问题的联系。

每次实验记录数据划分、随机种子、模型规模、上下文长度、batch size、精度、软件版本和硬件。困惑度比较使用相同的验证数据与分词方式；性能比较同时报告质量条件与测量方法。

实验采用 Jupyter Notebook 作为主要入口，穿插讲解、代码、输出与可视化；可复用逻辑保留为 Python 模块。[实验索引与环境配置](../experiments/README.md)。

## 第一章讨论安排

主题：语言模型究竟在建模什么——从一句话的概率到下一个 token。

1. 从 Shannon 对语言预测与信息量的研究出发，明确 token、序列和结束符。
2. 推导序列概率的链式分解，区分恒等式与有限上下文的建模假设。
3. 用小语料估计 unigram/bigram；观察未见组合与零概率问题。
4. 从最大似然推导平均负对数似然、交叉熵和困惑度。
5. 实验比较不同上下文长度、数据量和加性平滑强度，解释泛化与存储成本。
